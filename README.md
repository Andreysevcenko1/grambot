# grambot — монитор персон и криптовалют

Бот отслеживает публикации известных персон и новости об их связанных монетах,
а также объявления о листингах на Binance, Upbit и OKX. Уведомления
информационные: они **не предсказывают цену** и не являются финансовой
рекомендацией.

По умолчанию отслеживаются Дуров → TON, Маск → DOGE, Трамп → BTC/TRUMP,
Чжао → BNB, Бутерин → ETH, Сан → TRX, Яковенко → SOL, Хоскинсон → ADA,
Гарлингхаус → XRP и Сэйлор → BTC. Связь с монетой не означает, что персона
управляет ею или что новость повлияет на её цену.

Источники: публичный Telegram-канал Дурова, блог Бутерина, неофициальная копия
публикаций Трампа на trumpstruth.org, Telegram-каналы Watcher Guru, Wu Blockchain
и Cointelegraph, Telegram-канал Binance и публичные API Upbit и OKX. Опрос —
раз в 60 секунд по умолчанию. В уведомлении указано, является ли источник
публикацией автора, копией или сообщением СМИ, требующим проверки.

Для сообщения о персоне требуется имя и криптовалютный контекст; в личной
ленте имя не требуется, но контекст нужен. Только объявления, похожие на
новые листинги, попадают из биржевых лент. Это простые правила, они могут
пропускать новости или ошибаться. Копии, сообщения СМИ и тикеры листингов
нужно проверять по ссылке. Похожими заголовками бот старается не дублировать
сообщения. Посты старше 15 минут по умолчанию не отправляются, в том числе
после перезапуска.

**Ограничения:** прямого подключения к X/Twitter нет. Если источник недоступен,
задерживает публикацию или не репостит новость, бот может её пропустить.
Опрос раз в минуту не гарантирует доставку за минуту: источники, сеть и
Telegram добавляют задержки. Один источник не является подтверждением новости;
многие новости не вызывают роста цены или вызывают падение.

В режиме по умолчанию выключены ценовые, объёмные, ончейн- и деривативные
алерты, включая Whale Alert; классификатор настроения не используется.

## Установка на Linux с systemd

```bash
git clone https://github.com/Andreysevcenko1/grambot.git ~/grambot
cd ~/grambot
cp .env.example .env
nano .env
./scripts/install_systemd.sh
```

Укажите в `.env` токен от [@BotFather](https://t.me/BotFather) и
`TELEGRAM_CHAT_ID`. Не публикуйте токен; если он раскрыт, отзовите его в
BotFather и укажите новый в `.env`.

Обновление на сервере:

```bash
cd ~/grambot && git pull && ./scripts/install_systemd.sh
```

Логи: `sudo journalctl -u grambot -f`. Состояние:
`sudo systemctl status grambot`. Остановка: `sudo systemctl stop grambot`.

## Настройки

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `NEWS_MODE` | `watchlist` | `watchlist` — персоны и листинги; `classic` — прежний TON-монитор |
| `POLL_INTERVAL_SECONDS` | `60` | Интервал проверки; минимум 30 секунд |
| `WATCHLIST_MAX_AGE_MINUTES` | `15` | Максимальный возраст новости для отправки |
| `WATCHLIST_DISABLE` | пусто | Исключить персон по ключам через запятую, например `musk,trump` |
| `WATCHLIST_AGGREGATOR_FEEDS` | встроенные ленты | Заменить список СМИ лентами RSS/Atom или публичными Telegram-каналами через запятую |

Ключи персон: `durov`, `musk`, `trump`, `cz`, `vitalik`, `sun`, `yakovenko`,
`hoskinson`, `garlinghouse`, `saylor`. При неправильном ключе запуск завершится
с ошибкой. Дополнительные настройки и настройки старого режима — в
`.env.example`. `RSS_FEEDS`, классификатор и рыночные параметры относятся к
режиму `classic`, не к режиму персон.

Команды: `/watchlist`, `/status`, `/recent`, `/stats`, `/feeds`, `/check`,
`/test`, `/mute [минуты]`, `/unmute`, `/help`. Бот отвечает только
настроенному чату. `/feeds` показывает ошибки отдельных источников. `/stats`
показывает количество сигналов, а не эффективность или влияние на цену.

## Локальный запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
# Вписать TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID в .env
.venv/bin/python main.py
```

Для однократной проверки без Telegram используйте отдельную временную базу:
`DATABASE_PATH=/tmp/grambot-check.db .venv/bin/python main.py --once --no-telegram --no-supervise`.
Тесты: `.venv/bin/pip install -r requirements-dev.txt`, затем
`.venv/bin/python -m pytest -q`.
